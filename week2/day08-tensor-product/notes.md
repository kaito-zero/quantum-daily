# Day 8 (2026-11-23) 텐서곱과 두 큐비트

## 오늘 한 것

- 두 큐비트 상태가 진폭 네 개짜리 벡터라는 것 확인 (`day08.py` 1번)
- 텐서곱을 손으로 계산하고 `np.kron`과 비교, 순서가 중요하다는 것 확인 (`day08.py` 2~3번)
- Qiskit의 큐비트 순서(오른쪽 글자가 0번 큐비트)를 직접 확인 (`day08.py` 4번)
- 게이트도 텐서곱으로 4x4 행렬을 만들고 Qiskit Operator와 비교, 1,000번 측정 (`day08.py` 5~6번)

## 개념 정리

1. 큐비트 두 개의 상태는 진폭 네 개짜리 벡터다. 칸의 순서는 `|00>`, `|01>`, `|10>`, `|11>`. 크기 제곱의 합은 1.
2. **텐서곱(⊗)**: `[a, b] ⊗ [c, d] = [ac, ad, bc, bd]`. 왼쪽 숫자 하나하나에 오른쪽 벡터 전체를 곱해서 이어 붙인다.
3. 텐서곱은 순서가 중요하다. `|0> ⊗ |1> = |01>`, `|1> ⊗ |0> = |10>`. 왼쪽에 놓인 큐비트가 이름의 왼쪽 글자가 된다.
4. **Qiskit은 오른쪽 글자가 0번 큐비트다.** 0번 큐비트에만 X를 걸면 `'01'`이 나온다.
5. 그래서 Qiskit 상태를 `np.kron`으로 만들 때는 큰 번호부터 적는다. `np.kron(1번 큐비트, 0번 큐비트)`.
6. 큐비트 하나에만 거는 게이트도 텐서곱으로 4x4가 된다. 0번에 H는 `I ⊗ H`, 1번에 H는 `H ⊗ I`. 둘 다 유니터리다.
7. 측정 결과 이름(`'01'` 등)도 오른쪽이 0번 칸이다.

## 뽑기 기계로 이해하기

| 용어 | 뽑기 기계로 보면 |
| --- | --- |
| 두 큐비트 | 기계 두 대를 나란히 놓고 한 번에 뽑는 것. 결과는 00, 01, 10, 11 네 가지 |
| 텐서곱 | 두 기계의 설정을 곱해서 네 결과의 설정을 만드는 것 |
| 칸 이름 `'01'` | 오른쪽 글자가 0번 기계, 왼쪽 글자가 1번 기계의 결과 |
| `I ⊗ H` | 1번 기계는 그대로 두고 0번 기계만 섞는 조작 |

## 오늘 쓴 코드

| 코드 | 뜻 |
| --- | --- |
| `np.kron(u, v)` | 텐서곱 u ⊗ v. 벡터에도 행렬에도 쓴다 |
| `f"{k:02b}"` | 0~3을 `'00'`~`'11'` 두 자리 이진수 글자로 바꾸기 |
| `QuantumCircuit(2)` | 큐비트 2개짜리 회로 |
| `qc.x(0)` | 0번 큐비트에 X |
| `Statevector(qc).probabilities_dict()` | 결과 이름별 확률. 예: `{'01': 1.0}` |
| `np.eye(4)` | 4x4 단위행렬 |
| `qc.measure([0, 1], [0, 1])` | 0번 큐비트는 0번 칸에, 1번 큐비트는 1번 칸에 적기 |

## 질문과 답

**Q1. 텐서곱은 왜 이런 모양인가?**

두 큐비트가 서로 상관없이 따로 있으면, "1번이 0이고 0번이 1일" 진폭은 두 진폭의 곱이다. 네 가지 조합을 다 곱한 것이 텐서곱이다. 확률로 보면 독립 사건의 확률을 곱하는 것과 같다.

**Q2. Qiskit은 왜 오른쪽이 0번인가?**

이진수와 같은 규칙이라서다. `'01'`을 숫자로 읽으면 1이고, 맨 오른쪽 자리가 1의 자리(0번)다. 그래서 칸 번호 k의 이진수가 곧 결과 이름이다. 교과서는 왼쪽을 첫 번째 큐비트로 쓰는 경우가 많아서 헷갈리기 쉽다.

**Q3. `I ⊗ H`에서 왜 H가 오른쪽인가?**

Qiskit 순서대로 (1번) ⊗ (0번)이라 0번 큐비트의 게이트가 오른쪽에 온다. 상태를 `np.kron(1번, 0번)`으로 만드는 것과 같은 규칙이다.

**Q4. 모든 두 큐비트 상태를 텐서곱으로 만들 수 있나?**

아니다. 텐서곱으로 만든 상태는 두 큐비트가 서로 독립인 경우뿐이다. 텐서곱으로 쪼갤 수 없는 상태가 얽힘이고, Day 10에서 다룬다.

## 실행 결과 (`day08.py`)

6번의 측정 횟수만 실행할 때마다 달라진다.

- `[0.5, 0.5, 0.5, 0.5]`의 확률은 각 0.25, 합 1.0
- `|0> ⊗ |1> = [0, 1, 0, 0]`, `|1> ⊗ |0> = [0, 0, 1, 0]`. 손 계산과 `np.kron`이 같다
- `|+> ⊗ |+> = [0.5, 0.5, 0.5, 0.5]`, `|+> ⊗ |0> = 0.707|00> + 0.707|10>`, `|0> ⊗ |+> = 0.707|00> + 0.707|01>`
- 0번 큐비트에 X를 걸면 `[0, 1, 0, 0]`, 결과 이름 `'01'`. `np.kron(|0>, |1>)`과 같다
- 0번에 H의 행렬은 `I ⊗ H`와 같고 `H ⊗ I`와는 다르다. `H ⊗ H`도 유니터리
- 1번에 H, 0번에 X를 걸고 1,000번 측정하면 `'01'`과 `'11'`이 반반 (예: `{'11': 529, '01': 471}`)
