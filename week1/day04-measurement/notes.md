# Day 4 (2026-11-19) 측정과 보른 규칙

## 오늘 한 것

- 진폭에서 측정 확률을 손으로 계산하고(보른 규칙), 1,000번 측정한 결과와 비교 (`day04.py` 1~2번)
- 측정 횟수를 늘리면 비율이 확률에 가까워지는 것 확인 (`day04.py` 3번)
- 측정이 상태를 바꾸는 것, 중간 측정이 간섭을 없애는 것 확인 (`day04.py` 4~5번)

## 개념 정리

1. **보른 규칙**: 상태 `[a, b]`를 측정하면 0이 나올 확률은 a의 크기를 제곱한 값, 1이 나올 확률은 b의 크기를 제곱한 값이다.
2. 크기만 본다. `[0.6, 0.8]`, `[0.6, -0.8]`, `[0.6, 0.8j]`는 전부 0이 36%, 1이 64%다.
3. 확률은 "많이 뽑았을 때의 비율"이다. 1,000번 뽑으면 정확히 640번이 아니라 그 근처가 나온다. 많이 뽑을수록 비율이 확률에 가까워진다.
4. **측정하면 상태가 바뀐다.** 0이 나오면 그 순간 상태는 `|0>`, 1이 나오면 `|1>`이 된다. 측정 전의 진폭은 남지 않는다.
5. 그래서 같은 큐비트를 바로 다시 측정하면 항상 같은 값이 나온다.
6. 중간에 측정하면 간섭이 사라진다. H - H는 항상 0이지만 H - 측정 - H는 반반이다.
7. 한 번의 측정으로는 0 또는 1 하나만 얻는다. 확률을 알려면 같은 상태를 여러 번 새로 준비해서 측정해야 한다.

## 뽑기 기계로 이해하기

| 용어 | 뽑기 기계로 보면 |
| --- | --- |
| 보른 규칙 | 설정값(진폭)에서 확률을 읽는 방법. 크기를 제곱한다 |
| 측정 | 뽑기 한 번. 뽑는 순간 기계의 설정이 나온 결과 쪽으로 바뀐다 |
| 다시 측정 | 설정이 이미 바뀌었으니 같은 결과만 나온다 |
| shots=1000 | 같은 설정의 기계를 1,000번 새로 준비해서 한 번씩 뽑는 것 |

## 오늘 쓴 코드

| 코드 | 뜻 |
| --- | --- |
| `np.abs(state) ** 2` | 보른 규칙. 진폭의 크기를 제곱해 확률 구하기 |

## 질문과 답

**Q1. 왜 640번이 딱 나오지 않는가?**

뽑기가 랜덤이라서다. 1,000번 뽑으면 보통 15번 안팎으로 벗어난다. 확률 64%는 "많이 뽑을수록 비율이 0.64에 가까워진다"는 뜻이다.

**Q2. 측정하면 상태가 바뀐다는 건 무슨 뜻인가?**

`|+>`는 측정 전에는 `[0.707, 0.707]`이다. 측정해서 1이 나오면 그 순간 `[0, 1]`이 된다. 다시 측정하면 항상 1이다.

**Q3. 그러면 shots=1000은 같은 큐비트를 1,000번 측정하는 것인가?**

아니다. 회로를 처음부터 1,000번 다시 실행해서 매번 한 번씩 측정하는 것이다. 같은 큐비트를 계속 측정하면 첫 결과만 반복된다.

**Q4. 왜 중간에 측정하면 결과가 달라지는가?**

H - H에서는 1로 가는 두 갈래가 서로 지워져 0만 남는다. 중간에 측정하면 상태가 `|0>` 아니면 `|1>`로 정해져서 갈래가 하나만 남고, 지워질 상대가 없다. 그래서 두 번째 H 뒤에는 반반이 된다.

**Q5. 결과 `'00'`, `'11'`은 어떻게 읽는가?**

결과 적는 칸이 2개일 때 문자열은 오른쪽이 0번 칸이다. `'11'`은 첫 측정과 둘째 측정이 모두 1이라는 뜻이다.

## 실행 결과 (`day04.py`)

측정이 들어간 줄은 실행할 때마다 달라진다. 아래 숫자는 한 번 실행한 예다.

- `[0.8, 0.6]`의 확률은 `[0.64, 0.36]`. `[0.6, -0.8]`과 `[0.6, 0.8j]`는 둘 다 `[0.36, 0.64]`. `[0.707, 0.707j]`는 `[0.5, 0.5]`
- `[0.6, 0.8j]`를 1,000번 측정하면 1이 640번 근처 (예: 618번, 639번)
- 측정 횟수별 1의 비율 (예): 10번 0.80, 100번 0.69, 1,000번 0.652, 10,000번 0.632, 100,000번 0.640
- `|+>`를 측정해 1이 나오면 상태는 `[0, 1]`이고, 다시 측정해도 1
- 연달아 두 번 측정하면 `'00'`과 `'11'`만 나온다 (예: `{'00': 505, '11': 495}`)
- H - H - 측정은 `{'0': 1000}`, H - 측정 - H - 측정은 0과 1이 반반 (예: `{'1': 517, '0': 483}`)
