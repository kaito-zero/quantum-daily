## 개념 정리

1. 큐비트의 **상태**는 숫자 두 개짜리 배열 `[a, b]`로 생각한다. 큐비트는 그 상태를 가진 물건이다.
2. 일반 비트는 0 또는 1 하나만 갖는다. 큐비트는 측정 전까지 숫자 두 개(a, b)를 동시에 갖고 있다.
3. 측정하면 0 또는 1 하나만 나온다. 0이 나올 확률은 a², 1이 나올 확률은 b²이다.
4. a² + b² = 1 이다. 퍼센트로 쓰면 두 확률의 합은 항상 100이다.
5. `|0>`은 `[1, 0]`에, `|1>`은 `[0, 1]`에 붙인 이름표다.

## 뽑기 기계로 이해하기

| 용어 | 뽑기 기계로 보면 |
| --- | --- |
| 큐비트 | 0 아니면 1이 나오는 뽑기 기계 |
| 상태 | 기계의 확률 설정 |
| 게이트 | 설정을 바꾸는 다이얼 (H는 50:50으로 맞추는 다이얼) |
| 측정 | 뽑기 한 번. 뭐가 나올지는 뽑기 전엔 모른다 |
| shots=1000 | 같은 설정으로 1,000번 뽑아서 비율 확인 |

## 질문과 답

**Q1. 왜 각 숫자를 제곱한 값이 확률인가?**

자연이 그렇게 동작한다는 규칙(보른 규칙)이다. 지금은 받아들인다.

예: `[0.6, 0.8]`이면 0이 나올 확률은 0.6 × 0.6 = 36%, 1이 나올 확률은 0.8 × 0.8 = 64%.

**Q2. 0 아니면 1이라면서 어떻게 0.6, 0.8 같은 상태가 있나?**

"0 아니면 1"은 측정 결과 얘기다. 0.6과 0.8은 큐비트의 값이 아니라 0과 1 각각에 걸린 비중(진폭)이다.

**Q3. 비중이란?**

측정했을 때 0 쪽, 1 쪽으로 얼마나 기울어 있는지를 나타내는 숫자다. 클수록 그 결과가 더 자주 나온다. `[1, 0]`은 완전히 0 쪽이라 항상 0이 나온다.

**Q4. 관측 전까지 0인지 1인지 모르는 것 아닌가?**

맞다. 이번 측정에서 뭐가 나올지는 모른다. 정해져 있는 건 결과가 아니라 확률이다. 확률 설정은 고정이 아니라 게이트로 바꾼다. 모든 큐비트는 `[1, 0]`에서 시작한다.

**Q5. 첫 번째를 X, 두 번째를 Y라 하면 100X² + 100Y² = 100인가?**

맞다. X² + Y² = 1 이고, 반지름 1인 원의 식과 같다.

**Q6. 극단적으로 기울면?**

완전히 편향된다.

| 상태 | 0이 나올 확률 | 1이 나올 확률 |
| --- | --- | --- |
| `[1, 0]` | 100% | 0% |
| `[0.995, 0.1]` | 99% | 1% |
| `[0.707, 0.707]` | 50% | 50% |
| `[0.6, 0.8]` | 36% | 64% |
| `[0.1, 0.995]` | 1% | 99% |
| `[0, 1]` | 0% | 100% |
