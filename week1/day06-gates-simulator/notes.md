## 개념 정리

1. **X**: 0과 1을 맞바꾼다(비트 뒤집기). **Z**: `|1>` 쪽 부호만 뒤집는다(위상 뒤집기). **Y**: 둘 다 하면서 j를 곱한다. `Y = j·X·Z`.
2. X, Y, Z를 파울리 게이트라고 부른다. 셋 다 두 번 걸면 원래대로 돌아온다.
3. **H**: 중첩을 만든다. 두 번 걸면 원래대로. `HZH = X`, `HXH = Z`.
4. **S**와 **T**: `|0>`은 그대로 두고 둘째 진폭만 돌린다. S는 90도, T는 45도. Z는 180도라서 `T·T = S`, `S·S = Z`.
5. 위상 게이트(Z, S, T)를 걸고 바로 측정하면 확률이 그대로다. H 사이에 넣으면 0이 나올 확률이 `cos²(θ/2)`가 된다(Day 2 공식). Z는 0%, S는 50%, T는 85.4%.
6. 여섯 게이트 모두 유니터리다. `S†`, `T†`는 반대 방향으로 돌아서 S, T를 되돌린다.
7. 시뮬레이터에서 `measure()`는 한 번 측정하고 상태를 바꾸고(붕괴), `sample()`은 여러 번 새로 준비해서 측정한 결과라 상태를 바꾸지 않는다.

## 뽑기 기계로 이해하기

| 게이트 | 뽑기 기계로 보면 |
| --- | --- |
| X | 0 칸과 1 칸의 설정을 맞바꾼다 |
| Z, S, T | 1 칸 설정의 방향만 돌린다. 바로 뽑으면 티가 안 난다 |
| H | 두 칸 설정을 섞는다. 방향 차이를 확률 차이로 바꿔 준다 |
| 시뮬레이터 | 기계의 설정(상태 벡터)을 직접 들고, 조작(행렬 곱)과 뽑기(보른 규칙)를 코드로 흉내 낸 것 |

## 질문과 답

**Q1. Y는 X와 무엇이 다른가?**

`|0>`에 걸면 X는 `[0, 1]`, Y는 `[0, 1j]`다. 바로 측정하면 둘 다 항상 1이라 구별이 안 된다. 차이는 진폭에 붙은 j(위상)뿐이고, 다른 게이트와 이어 붙였을 때 간섭으로 드러난다.

**Q2. S와 T는 측정 결과를 안 바꾸는데 왜 필요한가?**

바로 측정할 때만 안 보인다. H 사이에 넣으면 0이 나올 확률을 0%, 50%, 85.4%처럼 바꾼다. 양자 알고리즘은 이렇게 위상을 돌려 놓고 간섭으로 답을 확률에 싣는다.

**Q3. 테스트에서 랜덤 결과는 어떻게 비교했나?**

두 가지를 했다. 시드를 고정해서 다시 돌려도 같은 결과가 나오게 했고, 정확한 횟수 대신 "비율이 확률에서 0.015 안쪽"인지 봤다. 20,000번이면 흔들림이 0.0025 정도라 넉넉한 기준이다.

**Q4. 무작위 회로 200개 테스트는 왜 했나?**

게이트 하나씩만 맞으면 순서를 잘못 곱하는 실수(Day 5)를 못 잡을 수 있다. 1~12개를 무작위로 이어 붙인 회로까지 Qiskit과 같으면 행렬 곱 순서도 맞다고 볼 수 있다.

## 실행 결과 (`day06.py`, `test_qubit_sim.py`)

5번과 6번의 측정 횟수는 실행할 때마다 달라진다. 아래는 한 번 실행한 예다.

- `T = [[1, 0], [0, 0.707+0.707j]]`, `Y = [[0, -1j], [1j, 0]]`
- `Y|0> = [0, 1j]`, `S|+> = [0.707, 0.707j]`, `T|+> = [0.707, 0.5+0.5j]`
- `T·T = S`, `S·S = Z`, `HZH = X`, `Y = j·X·Z`, T를 8번 곱하면 I. 모두 True
- 여덟 게이트(S†, T† 포함) 모두 유니터리
- `|+>`에 Z, S, T를 걸고 바로 측정하면 모두 `[0.5, 0.5]`. H 사이에 넣으면 Z는 `{'1': 1000}`, S는 반반, T는 0이 856번
- 무작위 게이트 6개짜리 회로에서 내 시뮬레이터와 Qiskit의 상태가 같다
