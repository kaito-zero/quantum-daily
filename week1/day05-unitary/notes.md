## 개념 정리

1. 게이트는 숫자 네 개가 들어 있는 2x2 행렬이다. 게이트를 건다는 것은 행렬을 상태 벡터에 곱한다는 뜻이다.
2. **행렬 × 벡터**: 결과의 첫째 숫자는 행렬 첫째 줄과 벡터를 짝지어 곱해서 더한 값이다. 둘째 숫자는 둘째 줄로 같은 일을 한 값이다.
3. **행렬 × 행렬**: 게이트를 연달아 거는 것은 행렬끼리 곱하는 것과 같다. `H @ H = I`, `H @ Z @ H = X`.
4. 식에서는 나중에 건 게이트가 왼쪽에 온다. 회로가 "X 먼저, H 나중"이면 행렬은 `H @ X`다.
5. 행렬 곱은 순서를 바꾸면 결과가 달라질 수 있다. `H @ X`와 `X @ H`는 다른 행렬이다.
6. **켤레 전치(†)**: 행과 열을 바꾸고(전치), 성분마다 j의 부호를 뒤집는다(켤레).
7. **유니터리**: `U†U = I`인 행렬이다. 게이트는 전부 유니터리다.
8. 유니터리 행렬은 확률의 합(진폭 크기 제곱의 합)을 1로 유지한다. 유니터리가 아닌 행렬을 곱하면 합이 1에서 벗어나서 더 이상 상태가 아니다.
9. `U†`는 `U`를 되돌린다. 그래서 게이트는 항상 되돌릴 수 있다. 측정은 게이트가 아니라서 되돌릴 수 없다.

## 질문과 답

**Q1. 왜 나중에 건 게이트가 식에서 왼쪽에 오는가?**

상태 `v`에 X를 걸면 `X @ v`, 거기에 H를 걸면 `H @ (X @ v)`다. 상태 벡터가 오른쪽 끝에 있어서 벡터에 가까운 행렬부터 곱해진다. 회로 그림은 왼쪽에서 오른쪽으로 읽고, 식은 오른쪽에서 왼쪽으로 읽는다.

**Q2. `*`와 `@`는 무엇이 다른가?**

`@`가 행렬 곱이다. `*`는 같은 자리에 있는 숫자끼리 곱하는 것이라서, 게이트 계산에 쓰면 틀린 답이 나온다.

**Q3. X, Z, H는 켤레 전치를 해도 왜 그대로인가?**

성분이 모두 실수라서 켤레를 해도 바뀌는 것이 없고, 대각선을 기준으로 대칭이라서 행과 열을 바꿔도 그대로다. S는 `1j`가 있어서 `S†`가 S와 다르다.

**Q4. 왜 게이트는 유니터리여야 하는가?**

상태 벡터는 확률의 합이 1이어야 한다(Day 3의 정규화). 유니터리 행렬은 벡터의 길이를 바꾸지 않아서 무엇을 걸어도 합이 1로 남는다. `[[2, 0], [0, 1]]` 같은 행렬은 `[0.6, 0.8j]`를 `[1.2, 0.8j]`로 만들어서 합이 2.08이 된다.

**Q5. 유니터리면 왜 되돌릴 수 있는가?**

`U†U = I`는 U를 건 뒤 `U†`를 걸면 아무것도 안 한 것과 같다는 뜻이다. 그래서 `U†`가 U의 되돌리기다. H는 `H† = H`라서 H를 한 번 더 걸면 되돌아간다. Day 1에서 H를 두 번 걸었을 때 0만 나온 이유다.

## 실행 결과 (`day05.py`)

측정이 없어서 실행할 때마다 같은 결과가 나온다.

- `X|0> = [0, 1]`, `H|0> = [0.707, 0.707]`, `Z|+> = [0.707, -0.707]`. 손으로 계산한 값과 `@`로 계산한 값이 같다
- `H @ H = [[1, 0], [0, 1]]`, `H @ Z @ H = [[0, 1], [1, 0]]`
- X 먼저, H 나중(`H @ X`)은 `[[0.707, 0.707], [-0.707, 0.707]]`. H 먼저, X 나중(`X @ H`)은 `[[0.707, -0.707], [0.707, 0.707]]`. 서로 다르다
- `M = [[1, 2j], [3, 4]]`의 켤레 전치는 `[[1, 3], [-2j, 4]]`. `S†`는 `[[1, 0], [0, -1j]]`
- X, Z, H, S는 유니터리(True), `A = [[2, 0], [0, 1]]`는 아니다(False). `A†A = [[4, 0], [0, 1]]`
- `[0.6, 0.8j]`에 H나 S를 걸면 확률의 합이 1.0, A를 걸면 2.08
- H를 걸고 H†를 걸면 처음 상태 `[0.6, 0.8j]`로 돌아온다
- 직접 만든 X, Z, H, S가 Qiskit의 행렬과 모두 같다. 회로(X 먼저, H 나중)의 행렬은 `H @ X`와 같다
